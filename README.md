# IPL Dashboard 🏏📊

An interactive **Indian Premier League (IPL) Dashboard** developed using **Power BI** to analyze and visualize IPL data through interactive charts, KPIs, and filters.

### 📌 Dashboard Highlights
- Interactive IPL data analysis
- Key performance indicators
- Team and player performance analysis
- Match-related data visualization
- Interactive filters and slicers
- Visual analysis of IPL trends and statistics

### 🛠️ Tools Used
- Power BI
- Power Query
- DAX
- Data Visualization

### 🎯 Objective
The objective of this project is to transform IPL data into an interactive Power BI dashboard that makes it easier to explore match, team, and player performance through visual analytics.
